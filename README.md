## 1. 개발 의도

이 앱을 왜 만들게 되었나요? 어떤 불편함이나 필요를 발견했나요?

-경진대회를 보고 간단하게 즐길 수 있는 게임을 고안하게 되었다. 아무 생각 없이 심심할 때 한 번 들어가는 게임을 만들고 싶었다.

## 3. 주요 기능과 사용 방법

| 기능 | 설명 |
| --- | --- |
| 기능 1 | 아케이드 모드로서 왕을 지키며 오래 버티는 게임을 플레이할 수 있음 |
| 기능 2 | 스테이지 모드로서 자신의 기물로 적을 공격하여 왕을 죽이는 게임을 플레이할 수 있음 |

**사용 방법**

1. 앱 주소에 접속합니다.
2. 게임 안내에 대해 읽어봅니다.
3. 아케이드 모드와 스테이지 모드 중 하나를 선택해 플레이합니다.
